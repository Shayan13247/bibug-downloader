# BiBug Downloader

**A multi-purpose desktop downloader for YouTube and Minecraft content.**

BiBug Downloader is a personal Windows desktop application developed by ShayanBB, designed to provide a simple and convenient way to discover and download digital content through a modern user interface.

## Features

### YouTube Downloader
- Search for YouTube videos.
- Download videos in multiple resolutions.
- Extract audio in MP3 format.
- Manage video and audio downloads.

### Minecraft Downloader
*Currently under development.*

Planned features:
- Search Minecraft mods and modpacks.
- Browse resource packs and shaderpacks.
- Filter content by Minecraft version.
- Support for Forge, Fabric and NeoForge.
- Download management.

## Technology Stack

- Python
- Flask
- HTML, CSS and JavaScript
- yt-dlp
- CurseForge API (integration planned)
